Pseudo DOM

A comprehensive mock of the browser DOM for Node - real querySelector, event dispatch, and HTML parsing, without a browser.

View on GitHub Documentation

This one mocks the DOM for environments that don't have one (Node, tests) - since you're already in a real browser, installGlobal() has nothing to do here. See the GitHub README for a runnable example, or open the console to look at pseudoDom directly.
