Pseudo DOM

A comprehensive mock of the browser DOM for Node - real querySelector, event dispatch, and HTML parsing, without a browser.

It mocks the DOM for environments that don't have one (Node, tests). Since you're in a real browser, the demo below puts that to the test: it asks pseudo-dom and this browser's own DOM the same questions and shows both answers. Or open the console to use pseudoDom directly.
