JSON File DB

A small query engine that treats a folder of JSON files as a database, with a SQL-like query string instead of a query builder API.

Documentation View on GitHub

It reads and writes real files, so it's Node-only and there's no browser bundle to demo here. Its public API (configure, create, query, describe, drop) is in the docs, and Workout Planner runs on it.
