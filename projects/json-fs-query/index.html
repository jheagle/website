JSON Filesystem Query

A small query engine that treats a folder of JSON files as a database, with a SQL-like query string instead of a query builder API.

Documentation View on GitHub Try the demo

It reads and writes real files in Node, and reads work in a browser too, over fetch(). The demo below queries a small library database kept as JSON files on this site. Workout Planner runs on it too.

Try it: a library database

Authors, books, members and loans, as JSON files. Ask a question or write your own read. The library's "today" is 2026-11-01. The same sandbox is on the projects page.
