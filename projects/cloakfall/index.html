Cloakfall

Every fleet is cloaked. Fire blind into the dark. The last fleet still hidden wins. A free-for-all, hidden-fleet grid game built as the real-world proving ground for the JSON DOM/Matrix DOM ecosystem - not a toy example, an actual playable app.

Documentation View on GitHub Play the game

2 to 4 fleets, any mix of players and robots: solo, hot-seat on one screen, online with friends, or just watch the robots hunt each other. Strict TypeScript throughout, with robot opponents that hunt by ship density, and full game-state management built entirely on JSON DOM's trait system and Matrix DOM's grid helpers for the boards.

Fully keyboard playable (Tab onto a board, arrow keys to move, Enter to fire) and screen-reader friendly: every cell is named by its coordinate and what it shows, and a hidden ship is never announced.

Formerly "Battleship": renamed in November 2026, since that name is Hasbro's trademark.
