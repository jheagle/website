    Module track

    Anonymous play events, sent to GoatCounter (https://www.goatcounter.com/help/events) when the page has its counter: the website's copy of the game does, this repo's own index.html doesn't, and neither do the tests or the server. Events only name what happened (a mode, a setting, how a game ended), never a player's name or anything typed.

    Every event is cloakfall-<name>, counted each time it happens (no_session), so the dashboard shows how often games start, finish or are left, not how many visitors did so.
