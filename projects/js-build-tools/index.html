js-build-tools

The shared build, test and documentation pipeline (Gulp-based) behind every other project here: TypeScript compiling, CommonJS distribution files, browser bundles, Jest, linting, and TypeDoc or jsdoc HTML docs.

Documentation View on GitHub

It runs in Node as part of each project's build, so there's no browser demo. Its output is everywhere on this site, though: every bundle and every Documentation link here came from it.
