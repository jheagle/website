JSON DOM

A from-scratch virtual-DOM framework in TypeScript, built around a composable trait system rather than deep inheritance.

Documentation Try the demo

Source is private, but the framework is proven out in Battleship, a full game built on top of it. Try it below, or open the browser console to use jsonDom directly.
